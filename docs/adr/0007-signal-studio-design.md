# ADR 0007: an expressive, lightweight signal studio

Status: accepted and implemented.

Pulse uses midnight surfaces, electric violet, acid lime, and coral data accents, with Space Grotesk display type, Inter interface text, and JetBrains Mono labels. Local font assets include their licenses. The default homepage is the presentation-led landing; /dashboard opens the working monitoring application. /welcome remains an alias.

The hero uses an original vector signal sculpture, orbital motion, pointer depth, floating metrics and interactive sample modes. Request phases and visitor graphics make the product concrete without adding long copy. Sample metrics are labeled; the sculpture does not claim multi-region probing. CSS transforms and SVG replace a heavy 3D runtime. Motion is disabled when reduced motion is requested.

Application charts use responsive native SVG with smooth, bounded interpolation through measured points, gradient areas, keyboard inspection, crosshairs, and a data-table alternative. The health dial derives its segments from actual monitor states. Each metric has a distinct representation; visitor counts do not borrow a latency-history sparkline. The audience donut and legend share the same recorded page-view distributions.

Frontend budgets continue to include every deferred chunk, and the presentation layer remains independent of API availability. Browser tests cover landing controls, primary-action routing, audience selection, both themes, mobile layout and automated WCAG checks. Lighthouse measures the new landing independently.
